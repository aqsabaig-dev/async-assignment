Q1. Bank Account Withdrawal

Create a Promise for withdrawing money. Account balance = Rs. 10,000. Withdrawal amount = Rs. 7,000. If balance is sufficient, resolve the Promise. Otherwise, reject the Promise. Use .then() and .catch() to display the result.

Q2. Online Exam Result

Create a Promise that checks student results. Marks 50 or above: Pass. Marks below 50: Fail. Marks greater than 100 or less than 0: Invalid marks. Handle the result using .then() and .catch().

Q3. Product Delivery System

Create a Promise for an online shopping delivery. Use setTimeout() to simulate a 3-second delivery process. After 3 seconds, resolve with "Product Delivered Successfully". If delivery is unsuccessful, reject with "Delivery Failed". Display the result using .then() and .catch().

Q4. Promise Chaining

Create a Promise that performs these operations: Start with a number: 10. Add 20. Multiply the result by 2. Subtract 5. Display the final result. Use Promise chaining with multiple .then() methods.
